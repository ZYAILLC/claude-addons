# zy-themes

一个 Claude Code mod，在 Claude 桌面应用的对话区后面放一套主题：6 幅内置画作（其中 3 幅带动画），或者你自己的图片。画会铺在对话区后面；动画主题上，桌面应用会给面板加一层磨砂玻璃，保证文字看得清。每个内置主题还会按画的颜色给窗口换一套配色（侧边栏、对话区、卡片、代码）。

| 主题 | 窗口 | 背景 |
| --- | --- | --- |
| `sakura` | 浅色 | 樱花晨曦：粉色晨光里，樱花枝垂在薄雾湖面上 |
| `inkwash` | 浅色 | 水墨山水：宣纸上的水墨远山，云雾缭绕，夕阳微暖 |
| `petals` | 浅色 | 花瓣微风：春日山坡上的樱花树，花瓣随风飘落（动画） |
| `moonlit` | 深色 | 月下湖光：一轮满月映照静谧的山间湖泊 |
| `fireflies` | 深色 | 萤火森林：月光洒进林间空地，萤火虫轻轻飞舞（动画） |
| `starlit` | 深色 | 星海：银河横跨平静的海面，繁星闪烁，偶有流星（动画） |

这些画是用图像模型为这个 mod 生成的。动画主题里，画面会缓慢推移，上面还有一层光影动画。

## 安装

```
/plugin marketplace add ZYAILLC/claude-addons
/plugin install zy-themes@claude-addons
```

在 Claude 桌面应用里：点输入框旁的 **+**，选 **Plugins**，用 **Add marketplace** 添加 `ZYAILLC/claude-addons`，再点 **Add plugin**，选 `zy-themes`。

## 用法

| 命令 | 作用 |
| --- | --- |
| `/zy-theme` | 在对话旁打开 **Themes** 侧边面板（见下）。 |
| `/zy-theme list` | 列出所有主题和你的图片。 |
| `/zy-theme <名字>` | 把主题应用到本项目。本项目其他打开的会话在下一轮也会换上。 |
| `/zy-theme <名字> session` | 只应用到当前会话。 |
| `/zy-theme <名字> all` | 应用到所有没有单独设置主题的项目。 |
| `/zy-theme image <路径>` | 用你自己的图片（JPEG 或 PNG；macOS 上 HEIC 等格式也行）当背景。同样可以加 `session` 或 `all`。 |
| `/zy-theme remove <名字>` | 删掉你的一张图片。 |
| `/zy-theme off` | 清除本项目的主题。`off session`、`off all` 同上。 |

会话先用自己的设置，没有就用项目的，再没有就用所有项目的。

## Themes 面板

在桌面应用里，输入框上方有一个 **🎨** 按钮，点一下打开面板；装了 [zy-quota](../zy-quota/README-zh.md) 时，按钮放在额度条那一行的末尾。可以在插件的 **Theme button** 设置里关掉它。

- **📂 打开图片…**：弹出系统的选择文件窗口（macOS），选中的图片立即成为背景。
- **↺ 重置**：恢复原样。
- 下面是所有内置画作和你加过的图片的缩略图，点名字就会使用；带 ▶ 的是动画。

在面板里的选择对所有项目生效。只想改某个项目或某个会话，用上面的命令。

面板默认是英文，点面板里的 **中文** 按钮可以把面板和主题按钮切换成简体中文，选择会记住。命令的回复保持英文。

## 自己的图片

背景图片必须放在 mod 自己的目录里，最大 1 MiB、每边不超过 4096 像素。`/zy-theme image` 会把你的图片复制过去：

- macOS 上会缩放到 2560 像素并存成 JPEG，所以多大的图都可以。
- 其他系统上，小于 1 MiB 的 JPEG 或 PNG 原样复制。

原始路径会记下来：mod 更新替换了目录后，会从原位置重新复制。窗口会裁掉图片边缘，重要的内容尽量放在中间。用自己的图片时，窗口保持应用原来的配色。

## 使用条件

- 需要最新版的 Claude 桌面应用。只有桌面和手机应用会画主题；在终端或编辑器里命令照样能用，选择也会保存。
- 旧版 Claude Code 不支持这些主题，这时命令会提示你更新。
- 有些版本的桌面应用只画主题的配色，还不画背景，这时窗口会换成画的颜色，但对话区后面没有图。等应用支持背景后，图会自动出现，不用改 mod。
- 如果回复说这个窗口不显示主题，或者什么都没变：先更新桌面应用（**Claude > Check for Updates…**），完全退出再打开，然后在 Code 标签页新建一个本地会话。更新前就开着的会话会一直显示应用自己的样子。
- 系统开启“减少动态效果”时，动画场景会静止。

## 保存的数据

每个会话、每个项目（按目录）和所有项目的主题选择，以及你的图片列表，都存在本机 Claude Code 给这个 mod 的存储里。不向任何地方发送数据。
